# downloadKnots

Public downloads for TechnologyKnots apps. Installers are published as **GitHub Releases** (not committed to the repo), because GitHub rejects files over 100 MB in git and over 25 MB in the browser uploader, and the installers are larger than that.

## Knottify desktop
Files: `Knottify-Setup-Windows.exe`, `Knottify-Mac.dmg`, `Knottify-Linux.AppImage`.

To publish or update them: **Releases → Draft a new release** (or edit the existing one) → tag `latest` → drag the three files in → **Publish release**. Keep the file names the same so the links never change:

- https://github.com/technologyknots/downloadKnots/releases/latest/download/Knottify-Setup-Windows.exe
- https://github.com/technologyknots/downloadKnots/releases/latest/download/Knottify-Mac.dmg
- https://github.com/technologyknots/downloadKnots/releases/latest/download/Knottify-Linux.AppImage
